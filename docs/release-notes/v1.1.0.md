## Neu in 1.1

- **Updates aus der App:** *Einstellungen → Updates* zeigt die installierte Version, sucht nach einer neueren und spielt sie mit **„Jetzt aktualisieren“** ein – mit Fortschrittsanzeige, Release-Notizen und SHA-256-Prüfung des Downloads.
  - Installer-Fassung: Der neue Installer läuft still im Hintergrund und startet KryptoQuest danach neu.
  - Portable Fassung: Die neue EXE ersetzt nach dem Beenden die bisherige Datei (gleicher Dateiname).
- Beim Start wird automatisch nach Updates gesucht (abschaltbar). Ist eine neue Version da, erscheint ein Hinweis und ein Punkt an „Einstellungen“; nach dem Neustart meldet KryptoQuest, ob das Update eingespielt wurde.
- Spielstand und Einstellungen bleiben bei Updates erhalten.

## Wichtig beim Umstieg von 1.0

Version 1.0 enthält den Updater noch nicht. Für den Schritt auf 1.1 also einmal von Hand installieren (Installer drüber installieren bzw. die neue portable EXE verwenden); ab 1.1 geht es dann aus der App heraus.

## Downloads

| Datei | Zweck |
|---|---|
| `KryptoQuest-Setup-1.1.0.exe` | Installer mit Startmenü- und Desktop-Verknüpfung |
| `KryptoQuest-1.1.0-portable.exe` | ohne Installation startbar |
| `SHA256SUMS.txt` | SHA-256-Prüfsummen der beiden Dateien |

Voraussetzung: Windows 10 oder 11, 64 Bit. Die EXE-Dateien sind nicht code-signiert; Windows SmartScreen fragt deshalb beim ersten Start nach (*Weitere Informationen → Trotzdem ausführen*).
